# Dog photos

Put dog photos here (.jpg, .jpeg, .png or .webp). In the Dogs tab of the Google Sheet,
type the exact file name in the photo_file column, for example `luna.jpg`.

Easiest way to add one: on GitHub, open this folder, click "Add file" -> "Upload files",
drag the photo in, then click "Commit changes". See HANDOFF_GUIDE.md.

Tip: photos about 1200 pixels wide (landscape) look best and load fast on phones.
